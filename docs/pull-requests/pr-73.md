## Description

ADR-0005 requires final record hashes and signed checkpoints before the durable sink can acknowledge writes. Add the I/O-free v1 format and cryptographic layer behind the off-by-default `audit` feature, so #11 can build the durable writer on the final format after this PR merges. This is PR A of the agreed serial implementation, rebased onto `dev` including #69 and #71. The README retains both semver and audit sections, and the flake retains cargo-semver-checks.

## Changes Made

- Validated Entry/Value schema, ascending tag + u32 length encoding, genesis and record hashes, and checkpoint message encoding excluding only the signature tag.
- Resumable trail-wide MMR with digest-string leaves and right-to-left peak bagging. Golden roots reproduce tessera-core `f08255d` for all sizes 0..=2048 through aggregate vectors; no tessera dependency.
- Signer trait, raw-hex seed parsing with redacted Debug and zeroization, pure Ed25519 signatures and strict verification. RFC 8032 and independent checkpoint vectors cover signing.
- Parser rustdoc and the ADR key-file format prominently explain that a 64-hex public key is accepted as a seed and derives a different key. Callers must supply the secret seed and check the derived public key against their trusted key id; the raw-hex v1 format permits no disambiguating header or prefix.
- Matchable audit error kinds; documentation describes this provisional low-level API and its limits. OTLP serialization with the shared encoder, file permissions, durability and multi-process behavior belong to PR B. No trail verification API/CLI or rotation, receipt-range, archiving or revocation policy is implemented.
- Default and audit variants run the complete flake checks; precommit clippy includes all features.

Dependencies (all optional): BLAKE3 1 with std/pure implements the fixed digest; ed25519-dalek 2 with std/zeroize/fast implements checkpoint signatures. A direct zeroize dependency erases temporary parsed seed bytes on success and error, reusing dalek's transitive crate without adding another package to the audit graph. BSD-3-Clause is permitted through crate-scoped license exceptions for exactly curve25519-dalek, ed25519-dalek and subtle: permissive, notice-retaining and compatible with Apache-2.0 distribution. Default normal/build dependency trees are identical before and after.
