# [PR 190](https://github.com/vig-os/vigil/pull/190) feat(audit): verifier chain engine and entry points (#13 V3a-2)

## Description

Add the collecting verifier engine over the merged V3a-1 input layer. Verification selects a pinned trail before reading, collects decoder, chain and gap findings, checks every conflicting candidate, and reports deterministic results across native segments and shipped copies.

Round 2 implements ruling 13-V3-d3: every native gap is reported once, pessimistically, so no fragment line slips past verification. Decoder findings carry `seq` when the decoder read it.

Round 3 fixes gap attribution so each native gap finding points at the gap's first physical line and names its line range, byte length and the attesting line/seq in its detail (ADR d11, ruling 13-V3-d3 point 5). Every decoder error raised after `audit.seq` has been read now carries that `seq`, attached once at the end of the codec rather than at each error site. CHANGELOG wording for `TornWriteRepaired` is corrected: it is an attestation with no preceding fragment, not an unattested repair.

The public verifier explicitly remains incomplete until #13 V3b–V8/R10 and C1. V5 is what later promotes a covered `TornWrite` to `TornWriteRepaired`; nothing here excuses evidence that only a later slice owns.

## Changes Made

- Expose `verify` and `Verifier::{new, trail, verify_dir, verify_files}` with `AuditError` read/configuration errors.
- Collect genesis, missing sequence, previous hash, duplicate, conflict, trail, clock and native checkpoint-boundary checks. Deduplicate authenticated hashes and link through either conflicting predecessor.
- Report native gap findings per ruling 13-V3-d3: `TornWrite` when `audit.repaired` matches the span digest, `RepairMismatch` on a missing or different attestation, a trailing gap as `TornWrite` with the bytes-to-EOF digest, a shipped-copy fragment line as `Unparsable`, and `audit.repaired` with no preceding gap as `TornWriteRepaired` "fragment not present".
- Round 3: every mid-file and trailing gap finding uses the gap's first physical line and names its line range, byte length and the attesting line/seq in its detail. Decoder errors raised after `audit.seq` has been read carry that `seq`, attached once in the codec.
- Preserve located input context for V3b, update the stable API snapshot/allowlist, and accept only the implemented ADR §19.2 surface.
