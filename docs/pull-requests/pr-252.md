# [PR 252](https://github.com/vig-os/vigil/pull/252) feat(audit): add Verifier::receipts and reconcile records against them

## Summary

Adds `Verifier::receipts(impl IntoIterator<Item = (u64, [u8; 32])>) -> Self` so a stopped-trail verifier reconciles the application's stored receipts against the verified history (ADR-0005 decision 5 "Receipt reconciliation"; ruling 13-V7-d1 points 2-5 and clarification 13-V7-d1a).

The call turns reconciliation on, so `.receipts([])` still reports every in-range `audit.record` as `NoReceipt` (error). A second call adds to the receipt set; identical receipts collapse, and two receipts for one `seq` are each evaluated independently. Operator `vigil.audit.*` records are included; checkpoints are not reconciled. A receipt whose `seq` is strictly below an accepted `start_from` or strictly above `end_before`'s `E` is set aside through the shared position classifier as `OutOfRange` (info) when the start or end is anchored, `UnanchoredStart` or `UnanchoredEnd` (error) otherwise, with subject `receipt seq <s> hash blake3:<64 hex>`.

A receipt matches when the verified set holds exactly one distinct record at its `seq` with that hash; otherwise `ReceiptMismatch` (error) at the receipt's `seq`, unlocated, with the first failing detail: `no record`, `seq is forked`, or `hash differs (record blake3:<64 hex>)`. At a forked `seq` the match rule fails closed (clarification 13-V7-d1a point 1): no receipt can match any copy, and every distinct non-checkpoint record there is `NoReceipt` at its own first copy.

The reconciled range runs from `seq 0` or the accepted `start_from` through the last record in the files. Under `end_before`, file records at or above the end checkpoint's `seq` are `TrailEnded` and not reconciled (clarification 13-V7-d1a point 2); a receipt naming an end-record line is still matched (point 3), and a receipt above `E` (the end record's last line) is set aside. The file-record cut reads the end checkpoint's `seq` from the shared position classifier, the same place `TrailEnded` opens.

`waive`, `receipts_from`, `receipts_live` and resume-gap confirmation land in later #13 work.

## Non-test diff

About 260 non-test lines across `src/audit/mod.rs` (`NoReceipt` / `ReceiptMismatch` rustdoc), `src/audit/verify/mod.rs` (`Verifier::receipts`), `src/audit/verify/receipts.rs` (new module), `src/audit/verify/engine.rs` (wiring) and `src/audit/verify/position.rs` (position classifier). The reconciliation module iterates the engine's already-sorted `(is_end_record, path, line, hash)` copies with a per-hash `or_insert`, picking the same first copy `first_copy` would return without a dead "no copy for this hash" arm.
