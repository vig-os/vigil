# [PR 105](https://github.com/vig-os/vigil/pull/105) feat(audit): public writer surface and mirror_to_logs (B3a)

## Description

Expose the ADR-0005 public audit writer as thin adapters over the durable sink. A successful record returns a durable receipt; optional log mirroring runs after the directory lock is released and emits only action, object, seq and the blake3 hash string.
