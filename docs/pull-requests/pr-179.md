# [PR 179](https://github.com/vig-os/vigil/pull/179) feat(audit): schema-checked writer, typed attributes and the personal-data rule (#164 CP2)

## Description

Adds a usable schema-checked audit writer: callers open a trail with `AuditConfig::schema` and attach typed values with `Entry::attr`. Invalid record shapes fail with `InvalidEntry` before directory locking, and rotate/resume require opaque operator references under a schema. Every written line uses the unchanged v1 encoder.

## Type of Change

- [x] `feat` -- New feature

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- Share decoded-entry schema validation with the writer so CP4 can use the same checks; render canonical attribute blocks and complete the unstable primitive's attribute refusal.
- Cover P5–P8, replacement attributes, object-kind spellings, reader/hash round trips, schema retention and schema-less operator compatibility. Each P6 refusal asserts no lock acquisition, identical live bytes and an unchanged next sequence.
- Document the personal-data rule, salted commitment duty, operator schema duty, erasure evidence and checkpoint/anchor advice. Accept only the implemented CP2 shares of ADR-0005 amendment 13.

### Added
