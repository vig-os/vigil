# [PR 147](https://github.com/vig-os/vigil/pull/147) feat(audit): vigil-audit operator commands and checkpoints(dir) (#13 C2)

## Description

Adds the six ADR-0005 operator commands and stable `audit::checkpoints(dir)`. Operators can create trails, generate keys, retain clean-stop heads, rotate keys, checkpoint and resume loss from the shell. `verify` remains #13 C1.

## Type of Change

- [x] `feat` -- New feature

## Changes Made

- Standard-library argument parsing, public-API-only command implementations and output/error modules.
- Snapshot retry for checkpoint listing, including the live file.
- Explicit close for create/resume and successful-output echo on stdout failure.

## Changelog Entry

- `vigil-audit` operator commands (`keygen`, `create`, `checkpoints`, `checkpoint`, `rotate`, `resume`) and stable `audit::checkpoints(dir)` ([#13](https://github.com/vig-os/vigil/issues/13), C2).
