# [PR 122](https://github.com/vig-os/vigil/pull/122) test(metrics): prove Prometheus conformance end to end

## Description

Prove ADR-0003 d12/d21 on the pinned Collector 0.151.0 and Prometheus 3.12.0. The new oracle checks exact series identities and final cumulative values for scope sharing, poisoned collisions, clean metrics and every valid declaration in a shared translation fixture. No library behavior or public API changes.

## Changes Made

1. Add pinned `pkgs.prometheus` to the dev shell only; verified version 3.12.0, matching ADR-0003 Context. No new Cargo dependencies.
2. Add a metrics-gated example with exactly two explicit exports per process. Its bounded clock poll starts from the actual first export's latest timestamp, ensuring a different Prometheus millisecond for the second collection. Both timestamps and flush/shutdown results are printed. Poisoned cases retain a witness counter and return DataLost in both periods.
3. Share 149 translation rows between Rust and real-binary conformance. All 148 valid rows run independently through Collector → Prometheus. The leading-digit row is structurally marked translation-only with its d24 reason; a facade-validator test prevents valid rows from being excluded (ruling 7b3-d1). Package scope metadata comes independently from the example's `env!` values and has a Cargo test guard (ruling 7b3-d2).
4. Add the stdlib-only Python driver: ephemeral ports, a fresh TSDB, required scope promotion, `otlp_http`, disabled Collector telemetry, value-based polling, exact label/series sets, and cleanup of its own children. Absences are checked after every run reaches its final values.
5. Run the oracle after existing conformance in Linux CI. [Notified #46 that the future macOS lane must include it](https://github.com/vig-os/vigil/issues/46#issuecomment-6131174714).
6. Document mapping, configuration, scope/version labels and query cost under README Metrics → Prometheus; update README Conformance.
7. Add the changelog entry and remove the blank line splitting the Added list.

Conservative non-test changed-line count: 274, below 900. Python, fixture, fixture-reader changes and new tests are excluded as specified.
