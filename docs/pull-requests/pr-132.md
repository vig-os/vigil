# [PR 132](https://github.com/vig-os/vigil/pull/132) feat(audit): operator resume surface (B3d2b2)

## Description

Add `AuditConfig::resume` for operator recovery after structural loss. The call seals a present damaged live file unchanged, stages one opening-checkpoint/resume pair, and returns the resume receipt with a writer using the supplied signer. Validation, settlement, promotion and initial scanning share one directory lock.

## Changes Made

- Exact found-head validation, creation-only rollback and genesis recovery, including empty sealed segments followed by live loss.
- Shared staging rollback with the correct staging filename; explicit `ResumeOutcome`, readable staging reopen and one final directory fsync covering both renames.
- The returned handle acknowledges the resume receipt before handoff, retains its signer and follows best-effort Drop checkpoint behavior. Mirroring runs after unlocking.
- ADR-0005 amendment 9 Accepted on 2026-10-13, rulings through B3d2-d10; operator recovery and waiver rustdoc. Amendment 8 and amendment 10 remain unchanged.
- Pin the d9 lost-future-boundary limit: record/checkpoint/close refuse `CorruptTrail` without mutation, then a fresh open continues.
