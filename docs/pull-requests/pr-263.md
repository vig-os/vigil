# [PR 263](https://github.com/vig-os/vigil/pull/263) feat(audit): add Verifier::accept_run for reviewed runs

## Summary

Adds `Verifier::accept_run(seq, hash, run_digest, reviewer, reason)` so a reviewer clears a closed run with one line pinning the closing resume record and the run digest (ADR-0005 decision 11 "Review file" `accept-run`; ruling 13-V8-d1, clarification 13-V8-d1a). Implements items 1-3 (items 4-5 follow).

- **Match** replaces exactly these findings with `Accepted`: the run's `SegmentStructure` findings (run finding + per-segment ones on native segments of the run, `first_segment..last_segment`, excluding the closer per ruling 13-V4-d9), each loss point's `ChainBroken` and `SeqGap` for its named range matched on the loss point's `(file, seq)` so a shipped same-`seq` copy is never promoted, and `MmrMismatch` on every checkpoint in a segment of the run at or after the run's first loss point. The closing opening checkpoint lies in the excluded closer segment, so its `MmrMismatch` is never accepted; `Resumed`, the gap itself, and every other finding keep their severity.
- **Mismatches:** no record, forked `seq`, hash-differs, "not a resume record" and "run digest differs" each give `AcceptMismatch`. A resume that closes no run is `AcceptUnused` with the digest of nothing, `AcceptMismatch` otherwise.
- **Position (13-V8-d1 point 8, 13-V8-d1a):** a line is set aside under the start rule exactly when an accepted start exists, the line's `seq` is start + 1, and the verified set holds at that `seq` one unforked `vigil.audit.resume` whose hash equals the line's and whose opening is the start. Pre-computed from the merged records once in `engine::check` and handed to `position::Classifier`; the decision lives entirely in `position.rs` and never consults the run index (the run such a line closes lies wholly below the start and is never in the index). Every other line goes through normal matching, so a bogus `start+1` line never clears an error.
- **Reuse:** the run digest comes from `lines::run_digest` in `fold::emit_run_finding` (no recomputation); `receipts::mismatch` is the shared receipt match rule; `validate_reviewer` and `validate_reason` validate the subject for both `accept` and `accept-run`; the `vigil.audit.resume` predicate is `Summary::is_resume`; `set_aside`'s builder is the single place that emits the below-start / above-end finding shapes.
