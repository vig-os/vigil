# [PR 74](https://github.com/vig-os/vigil/pull/74) ci(msrv): enforce independent Rust compatibility lanes

## Description

Enforce ADR-0004 decision 11 with independent Linux MSRV and latest-stable lanes. MSRV builds/tests all features at Rust 1.95.0 and checks aarch64-apple-darwin; compiler and Cargo.toml drift fails before building. Latest stable is currently 1.99.0, resolved by the locked devkit fenix implementation with an independently hashed manifest; advance this manifest pin on each stable release. Warnings remain visible without blocking that lane.

## Changes Made

- Add independent flake shells, CI jobs and compiler-version guard with regression coverage.
- Document the six-month rule and minor-release-only MSRV raises.
- Keep src/ untouched. MSRV equals the dev pin today (1.95.0); this lane adds Apple-target coverage and starts testing an older compiler as soon as devkit advances.

- Rebase onto current `dev`, retaining #73 audit checks and all-feature clippy.
- Derive short-form MSRV comparison from `msrvVersion`, with both versions in drift errors.
- Locate the regression-test manifest relative to the test script, independent of the working directory.

### Manual Testing Details

A temporary README doctest using `std::assert_matches!` (stable since Rust 1.96) was committed and then reverted. [Proof CI run](https://github.com/vig-os/vigil/actions/runs/38101965980), [MSRV job](https://github.com/vig-os/vigil/actions/runs/38101965980/job/114359596143): Rust 1.95.0 rejected the doctest with `error[E0658]: use of unstable library feature assert_matches`; latest stable passed. Local negative doctest: exit 101. Because MSRV equals the dev pin, the dev-pin flake lane also rejected the probe. The initial `fmt::from_fn` probe was ineffective (stable since 1.93) and was corrected before recording this failure. Both temporary probe commits are reverted.

Round 2 validation: regression discovery from `/tmp` failed before the fix (exit 1, three missing-manifest errors), then passed from both `/tmp` and the repository (exit 0, four tests each). Nix assertion probes now accept 1.96/1.96.0 and reject 1.95/1.96.0; the prior assertion did the opposite. `just precommit` passed (exit 0). Rebased `nix flake check -L` passed (exit 0: 132 default and 138 audit nextest tests passed). [Fresh CI](https://github.com/vig-os/vigil/actions/runs/38103017609) passed all jobs, including both compatibility lanes, the flake check and CI Summary.
