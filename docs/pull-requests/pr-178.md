# [PR 178](https://github.com/vig-os/vigil/pull/178) feat(rotate): total-bytes cap with live-file reservation and the disk-use bound (#163, 163b)

## Description

Add an optional directory-wide telemetry byte cap. Pruning reserves each live file at its size limit or actual length, including a pending oversized write, and deletes rotated segments by `(stamp, signal, integer counter)` after age and count pruning. Audit and foreign files remain outside the budget.

Closes #163.

## Type of Change

- [x] `feat` -- New feature

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- Add `Config::max_total_bytes`, `RotationConfig::max_total_bytes`, and `VIGIL_MAX_TOTAL_BYTES`, preserving explicit `None` and zero.
- Preserve global configuration for cross-signal reservations and prune before oversized writes, including into an empty live file.
- Add locked observations, process fixtures, deletion-failure tests, retained-writer proofs, and public API coverage.
- Document visible and logical byte bounds and accept ADR-0002 amendment 3.

## Changelog Entry

- Optional directory-wide telemetry byte cap with live-file and pending-write reservations, oldest-first pruning after age and count, and a documented logical-byte bound including retained writer handles ([#163](https://github.com/vig-os/vigil/issues/163), slice 163b).
