# [PR 235](https://github.com/vig-os/vigil/pull/235) feat(audit): check revocation pins and confirmation in the verifier

## Summary

Extends the offline verifier with revocation pin and confirmation
checks per ADR-0005 decision 9 and amendment 8 (rulings 13-V5-d1
point 4, 13-V5-d3 and 13-V5-d4). For each key in the verified trail's
section carrying a `through=<s>:<h>` bound, in key-byte order, the
verifier now emits `RevocationMismatch` when the pin fails and
`RevocationUnconfirmed` when no trusted checkpoint strictly above `s`
is signed by another key. The two checks are independent, so one
bound can carry both findings.

A bound on key `K` is pinned when exactly one distinct record exists
at `s`, its hash is `h`, it is a checkpoint, and its `audit.key_id`
is `K` (amendment 8). A `SeqConflict` fork is not pinned
(fail-closed per ruling 13-V5-d2). Exactly one `RevocationMismatch`
detail is emitted per bound, chosen by the first failing condition
in this order (ruling 13-V5-d4 point 3): `no record at seq <s>` (no
location), `seq <s> is forked` (no location), `record at seq <s>
has hash blake3:<64 hex>` (at the first copy in the engine's merge
order, ruling 13-V5-d4 point 4), `record at seq <s> is not a
checkpoint`, or `record at seq <s> is signed by key <64 hex>`.
Confirmation requires a trusted checkpoint strictly above `s`
(`checked_add(1)`, ruling 13-V5-d4 point 2) signed by a different
key; a shipped-only trusted checkpoint confirms (ruling 13-V5-d4
point 5).

The module `src/audit/verify/revocation.rs` (183 lines) reads only
what `engine::check` already has from the one snapshot (ruling
13-V4-d5): the merged records per `seq`, the fork set, and the
crate-private trusted predicate from `signatures::trusted`. No
second pass over files. Wired into `engine::check` with the minimum
change (a single call after the main seq-loop).

The `end=` exemption of ruling 13-V5-d1 point 4 arrives with `end=`
itself in V5d; until then a retired trail without a confirming
checkpoint reports `RevocationUnconfirmed`.

Non-test diff: 259 added lines (260 with CHANGELOG), of which the
new module is 183 lines; two `FindingKind` rustdocs 46 lines; engine
wiring 6 lines; `TrustPolicy::bounds_in` 18 lines; `mod` declaration
3 lines; CHANGELOG 1 line; plus a handful of context lines in the
remainder.
