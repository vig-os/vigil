## Description

Apply ADR-0004 to configuration and composition, the first of three approved serial PRs. A consumer can build its own Registry, select its filter environment variable/default, add a stderr console, and find the actual log directory. Other consumer layers retain their own filters.

Exactly one successful vigil pipeline is allowed per process. Failed attempts release their reservation; a second pipeline returns `AlreadyRunning`, while a foreign subscriber returns `ForeignSubscriber`. The subscriber-install race shuts down the newly built provider before returning its error.

## Changes Made

- **ADR-0004 decision 2:** add `Config::layer`, filter/console builders, the permanent pipeline reservation, `Guard::dir`, and duration retention. Empty filter variables count as unset. The flock-like example compiles and runs as a test.
- **Decision 3, initialization portion:** add typed `InitErrorKind` values and sources, distinguish already-running pipelines from foreign subscribers, validate default filters, and clean up after a lost global-subscriber install race.
- **Decision 5:** make rotation fields private, add validated builders, remove `Copy`, and make the new public enums non-exhaustive. These items are justified by decision 6's table.

Breaking changes are required by decisions 2 and 5 (removing `retention_days`, public rotation fields and `Copy`) and decision 3 (typed initialization errors). This is the pre-publication API migration described by decision 12; no version bump is included.

The serialization writer and rotation internals are unchanged. No dependencies are added.

## Changelog Entry

### Added

- ADR-0004 configuration and composition APIs: `Config::layer`, `Console`, `Config::filter_env`, `Config::default_filter`, `Guard::dir`, and typed `InitErrorKind` errors; duration-based `Config::retention` and validated `RotationConfig` builders ([#42](https://github.com/vig-os/vigil/issues/42), [#36](https://github.com/vig-os/vigil/issues/36)).

### Changed

- **Breaking:** one successful pipeline permanently occupies the process slot, including after shutdown. Filters apply per layer; empty filter variables count as unset, and explicit `retention(None)` overrides environment retention ([#42](https://github.com/vig-os/vigil/issues/42)).
- **Breaking:** make `RotationConfig` fields private and remove `Copy` ([#42](https://github.com/vig-os/vigil/issues/42)).

### Removed

- **Breaking:** remove `Config::retention_days`; use `Config::retention(Option<Duration>)` ([#42](https://github.com/vig-os/vigil/issues/42)).
