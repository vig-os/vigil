# [PR 144](https://github.com/vig-os/vigil/pull/144) feat(traces): tracer pipeline builders and OTel layer config (#8 8c-1)

## Description

Adds the crate-private tracer provider and configured OpenTelemetry layer for #8 slice 8c-1. Storage resolves to Ready or Disabled before provider construction, and can transition to Closed at shutdown. Disabled storage builds a provider without processors: no serialization, queue, loss accounting, diagnostics or shutdown capture can run, while sampled span context remains active (ADR-0003 d5/d15). Closed storage reports failed spans. This slice does not install the pipeline through `init` or `Config::layer`.

## Changes Made

- Adds optional `tracing-opentelemetry` 0.34 without default features. Lockfile adds exactly `tracing-opentelemetry 0.34.0` and wasm-only `web-time 1.1.0` (ADR-0004 d7, OQ12).
- Builds ParentBased(AlwaysOn) tracing with explicit span limits, queue size, batch size 512 and 1-second scheduled delay. The synchronous SDK ignores export timeout and concurrency (ADR-0003 d6/d16, OQ10/OQ13/OQ20).
- Uses scope `vigil` without a version, explicit layer options including `with_level(false)`, and a per-layer spans-or-ERROR filter (ADR-0003 d13–d16, OQ2/OQ14).
- Removes dead-code expectations that became unfulfilled; keeps expectations where construction remains deferred to 8c-2.

New-API absence proof: removing the builder implementation makes the tests fail to compile with exit 101. Five runtime mutants each produced a failing test (exit 101), then passed after revert (exit 0): omitted sampler; omitted span limits; SDK default batch config; spans-only filter; counting a discarded Disabled batch as lost. A separate Disabled-to-I/O-error regression mutant also failed at runtime and passed after revert.

Round-two runtime mutants, each exit 101 → revert 0: restore the ReportingSpanExporter wrapper on Disabled (oversized probe); restore the ReportingSpanProcessor wrapper on Disabled (queue-one probe); substitute AlwaysOn for ParentBased(AlwaysOn); widen the event filter to include WARN.
