## Description

Release preparation currently leaves the crate reporting 0.0.0. The project-owned prepare hook now sets Cargo.toml and Cargo.lock to the train's X.Y.Z version on release/X.Y.Z before the draft release PR opens.

## Changes Made

Verify the checked-out release head equals branch_sha and the branch matches the supplied version. The stdlib-only, isolated-mode-safe script validates both TOML files before writing and changes only the root package version. Dry runs write nothing; an already-current version creates no commit. The hook uses the same pinned COMMIT_APP token action and API commit action as the freeze commit, with one attempt, and validates the release commit message before pushing. Document the version lifecycle in the hook.

Run seven regression tests through just precommit and the existing Nix Python check.
