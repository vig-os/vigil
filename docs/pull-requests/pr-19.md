# [PR 19](https://github.com/vig-os/vigil/pull/19) ci: run nix flake check in the CI extension

## Description

The managed `ci.yml` runs `just lint`/`just test`, which are Python recipes that skip without a `pyproject.toml` (vig-os/devkit#1811), so no CI lane compiled or tested the crate. The consumer-owned CI extension now runs `nix flake check -L` (clippy, fmt, nextest, doctests, docs), so `CI Summary` gates on them.
