## Description

Implement ADR-0005 amendment 13 CP1a: typed attribute kinds/values, canonical block rendering/parsing, and the reserved details prefix. Record construction now returns InvalidEntry for caller details starting with `vigil.attrs.`. Existing decoding and all v1 encoding/hash paths remain unchanged.

## Changes Made

Add FieldKind and AttrValue, shared key/value validators, canonical block helpers, boundary tests, and a typed-record golden vector checked against the frozen 0.1.0 encoder fixture.
