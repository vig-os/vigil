# [PR 24](https://github.com/vig-os/vigil/pull/24) docs(adr): lock the state directory instead of a lock file

## Description

Amends ADR-0002 (stays Accepted, with an "Amended 2026-10-09" line) to match PR #22 after its independent re-verification.

## Type of Change

- [x] `docs` -- Documentation only

## Changes Made

- Decision 3: exclusive `flock` on the state directory, not a `<signal>.jsonl.lock` file (a deleted lock file let two writers in: 2 `NotFound` of 48 000 appends, misordered records; a non-empty directory can't be unlinked). All signals in a directory share one lock.
- Decision 5: counter ≥6 digits, ordering by (stamp, integer counter), rotation via `hard_link` + `remove_file`, never replacing.
- New decision 11: signal names `[a-z0-9_]+`.
- New consequence: rotation lists and sorts the directory, so it is linear in the segment count (48 000-segment stress run ≈ 10 min).
