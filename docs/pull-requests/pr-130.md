## Description

Metrics-only flush failures and timeouts previously lost their signal label. Every populated `FlushError` part now renders its own wording and keeps its source beside that wording, using `: ` for the first part and `; ` thereafter. Programmatic kind, loss accounting and source chaining are unchanged.

ADR-0004 records architect ruling 113-d1: public error types and their programmatic accessors/chaining are promised, while human-readable Display/Debug text may change in any release with a CHANGELOG entry. README and all four implemented public error types document the exclusion; PropagationError remains planned.
