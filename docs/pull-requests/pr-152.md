# [PR 152](https://github.com/vig-os/vigil/pull/152) feat(audit): vigil-audit usage and --help (#13)

## Description

Make the shipped audit CLI discoverable: global help aliases and command help exit 0 on stdout; usage errors exit 2 with the synopsis on stderr. Verify is explicitly unavailable (#13).

## Type of Change

- [x] `feat` -- New feature

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- Derive help and required parser flags from one std-only command table matching ADR-0005 decision 11.
- Document help in README and fold it into the existing Added entry.
- Exercise global aliases, usage errors, per-command help, and bidirectional parser/help coverage in child CLI processes.
