# [PR 176](https://github.com/vig-os/vigil/pull/176) feat(rotate): per-signal rotation overrides and a rotated-segment count cap (#163, 163a)

## Description

Add an optional rotated-segment count cap and per-signal size, count and age overrides for #163, slice 163a. At open and after rotation, the writer prunes age first, then the oldest segments of its own signal until the count is met. Live files, audit files and foreign files survive; deletion errors leave segments counted while later deletions compensate, with one process-wide count warning only if the cap remains unmet.

## Type of Change

- [x] `feat` -- New feature

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- Add `SignalRotation`, `RotationConfig::max_segments`/`signal`, and `Config::max_segments`/`signal_rotation`. Fixed override slots preserve order-independent equality; one resolver supplies writer limits, including custom-signal fallback.
- Resolve ten new environment variables with signal builder > global builder > signal environment > global environment > default precedence. Explicit `None` disables a cap; count zero keeps no rotated segments, size zero clamps to one, environment age zero disables age pruning.
- Document the public surface, count bound, retained writer allowance, zero rules, environment names and precedence; update ADR-0004 and the stable API allowlist/snapshot. Amendment 3 remains Proposed.
