# [PR 137](https://github.com/vig-os/vigil/pull/137) docs(audit): deployment text for the audit trail (B3e-1)

## Description

README deployment text for the audit trail (B3e-1) plus two ADR-0005 residual fixes. Docs only; no code change. B3e-2 (§18.4 duties 2–5, the `--strict` note, the Consequences duty list) is a separate PR.

Closes #126. Refs #11, #12.

## Type of Change

- [x] `docs` -- Documentation only

## Changes Made

- README "Audit format (opt-in)": rewritten primitives paragraph (`Record` and `Record::parse_line` are public only under `--cfg vigil_unstable`) and subsections 1–12 below. Stale lines fixed: ~l.5 "audit being built", ~l.210 "traces and audit are planned" (traces are still #8 on dev; audit is available behind the `audit` feature), and the Stability "Audit format" bullet.
- ADR-0005: §18.3 residual 7 "Who catches it" now reads "routine `verify` with the start from the anchor-store entry (amended, #123)" with the matching §18.6 row (#126); the §18.6 row's stale "18.5, first bullet (l.1150)" cite lost its line number; amendment 9's R5'' tag at the `.audit-resume.jsonl` promotion bullet is now "(amendment 9, part 1, R5'', B3d2-d3)" (only that tag).
- There is no `vigil-audit` binary yet (#13): every procedure uses library calls, and each verify, waive and accept step is marked "(#13)". No CLI flags are invented.
