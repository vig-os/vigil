# [PR 29](https://github.com/vig-os/vigil/pull/29) test(conformance): compare rotated logs through the reference reader

## Description

Run the reference Collector on rich vigil logs across rotation and compare complete records by meaning. Empty and garbage lines between valid batches must preserve both neighbours.

## Type of Change

- [x] `test` -- Adding or updating tests
- [x] `ci` -- CI/CD pipeline changes

### Modifiers

- [ ] Breaking change (`!`)

## Changes Made

- Add a fixed 17-record example covering all AnyValue kinds, non-finite doubles, nested values, timestamps, trace/span IDs and multiple scopes/batches across two resources.
- Compare resource, scope and record multisets with protobuf default and numeric spelling normalization.
- Pin Collector-contrib 0.151.0 through the existing flake lock and print its version in CI.
- Include a valid unterminated EOF record in the manifest and exclude an unterminated garbage EOF line; require a non-empty manifest and use explicit checks active under `python -O`.
- Document the local command and leave metrics/traces extensions for #7 and #8.
- No new crate dependencies; Python comes from the pinned dev shell.

## Changelog Entry

- Collector reference-reader conformance in CI compares complete rich log records across two resources, rotation, empty lines, garbage input and unterminated valid/garbage lines ([#6](https://github.com/vig-os/vigil/issues/6))
