# [PR 219](https://github.com/vig-os/vigil/pull/219) refactor(audit): byte source for the segment walkers; surface report-pass read errors

## Summary

Thread an owned `storage::ByteSource` through the per-segment walkers
in place of `&File`, and fold in the fix for #218 along the lines this
change rewrites. Zero behaviour change on every existing reader path;
Collect changes only on I/O failure.

## What changed

- Walker signatures: `storage::{history_segment, scan, scan_closing,
  scan_staged, scan_inner}` and `SegmentBytes::new` now take
  `source: ByteSource` (consumed). `SegmentRead::{Sealed, Live}` carries
  the source; `SegmentSource::next_segment` constructs
  `ByteSource::File(file)` where the body previously returned `file`.
- `ByteSource` has one shipping variant (`File`). Rulings 13-V4-d5 (b)
  and 13-V4-d6 point 1 fix the `Read` / `Seek` / `try_clone` contract
  so a future non-file source lands under this same surface without
  widening it (portability to macOS, #46).
- `runs::classify`'s match arms and the span-handle capture
  pattern-bind the new field.

## Fix for #218

Under `Reaction::Collect`, every I/O failure in the report pass now
propagates as `AuditError::Io` instead of being swallowed into empty
spans (ADR-0005 decision 11; rulings 13-V4-d5 (d), 107-d2, 107-d3):

- `span_handle = source.try_clone()?` (was `.ok()`).
- `source.seek(SeekFrom::Start(0)).map_err(storage::io_error)?` (was
  `if seek.is_err() { return (Vec::new(), None); }`).
- `verify::lines::stream(...).map_err(storage::io_error)?` (was
  `match spans { Err(_) => (Vec::new(), heads), .. }`).
- `u32::try_from(segment_index)` is a checked conversion that errors
  as `AuditError::Io` on overflow (was `.unwrap_or(u32::MAX)`). A
  second `u32::try_from` on the run-local segment index is total by
  construction and documents the invariant via `.expect` instead of a
  saturating sentinel.
- The report-pass block uses `span_handle.expect(..)` to document its
  construction invariant, retiring the dead `None` branch.

Reuses the existing `storage::io_error` helper for the mapping.
