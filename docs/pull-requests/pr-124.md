# [PR 124](https://github.com/vig-os/vigil/pull/124) docs(adr): ADR-0005 amendment 10 leftovers, start-from source and span definition

Docs-only fix of the four items in #123 (amendment 10 leftovers) plus architect ruling 123-d1. Round 2 fixes the review blocker and nits.

- **N1:** every sentence that took `--start-from` from the archive record now says the operator passes the previous batch's batch-start anchor-store entry. No separate equality check is needed: the entry is the start input, and the record's equality with it is enforced by its own batch's step 7. A rewritten record `n-1` is caught by batch `n-1`'s step 7 (`AnchorMismatch`) and no longer affects batch `n`.
- **N2, N4:** l.464 wording, doubled parenthesis.
- **N3 (123-d1):** span definition (a) what is a record, (b) newline ownership, and a golden vector with two cases and run digests.
- Decision 18.6 rows added; CHANGELOG entry under Unreleased/Fixed.

Golden vector script and output (matches the reviewer's independent BLAKE3: with the old 12-byte tail it gave 725cc073…61f77 and c686d498…0671cdeb):

```python
# Golden vectors for the accept-run run digest (ADR-0005 amendment 10, rulings 107-d3 and 123-d1).
# Record lines are stand-ins of fixed length (a real record is a JSON line ending in LF):
# offsets depend only on lengths, and the digest only on the span bytes and `after`.
import struct, subprocess
def b3(b):
    return subprocess.run(["b3sum", "--no-names", "--raw"], input=b, capture_output=True, check=True).stdout
D_PREFIX = b"vigil.audit.v1.repaired\0"
RUN_PREFIX = b"vigil.audit.v1.run-ranges\0"
MAX = 2**64 - 1
REC4, REC5 = 211, 198                      # record line lengths, LF included
frag = b'{"seq":5,"ki' + b"\n"             # torn fragment + its repair newline (13 bytes)
unparsable = b"not json\n"                 # complete line the reader classifies Unparsable (9 bytes)
span1 = frag + unparsable                  # adjacent, so one maximal span (22 bytes)
tail = b'{"seq":6,'                        # newline-less tail after record 5 (9 bytes)
def run_digest(spans):                     # n = 0 ranges
    out = RUN_PREFIX + struct.pack(">I", 0) + struct.pack(">I", len(spans))
    for seg, after, ln, d in spans:
        out += struct.pack(">IQQ", seg, after, ln) + d
    return b3(out).hex()
def case(name, layout):
    print("== " + name)
    off, spans, last = 0, [], MAX
    for kind, val in layout:
        if kind == "rec":
            print("record seq %d: [%d, %d)" % (val[0], off, off + val[1])); off += val[1]; last = val[0]
        else:
            print("span at [%d, %d): %r" % (off, off + len(val), val))
            spans.append((0, last, len(val), b3(D_PREFIX + val))); off += len(val)
    print("file length", off)
    for seg, after, ln, d in spans:
        print("span seg=%d after=%s len=%d D=%s" % (seg, "u64::MAX" if after == MAX else after, ln, d.hex()))
    print("m=%d run digest blake3:%s" % (len(spans), run_digest(spans)))
case("case 1: record, span, record, tail", [("rec", (4, REC4)), ("span", span1), ("rec", (5, REC5)), ("span", tail)])
case("case 2: first span at the segment start", [("span", span1), ("rec", (5, REC5)), ("span", tail)])
```
