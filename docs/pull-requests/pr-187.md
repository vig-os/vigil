# [PR 187](https://github.com/vig-os/vigil/pull/187) feat(audit): TrustPolicy, the verifier's trust input (#13 V1)

## Description

Adds the verifier's validated trust input for #13 V1. `TrustPolicy` pins trail ids, signing keys, trail-local revocation bounds and retirement heads through a builder or a UTF-8 trust file. Both paths share semantic validation, including revocation consistency across trails. Invalid syntax fails closed; schema pins remain with #164 CP4.

## Type of Change

- [x] `feat` -- New feature

### Modifiers

- [ ] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

- Add the stable `TrustPolicy`, `TrustPolicyBuilder` and `TrailTrust` API, rustdoc and crate-private verifier queries.
- Share the const-generic lowercase hex decoder with typed attributes; preserve error categories.
- Preserve the underlying I/O source when reading a trust file fails, including `AuditError`'s existing `UnwindSafe` and `RefUnwindSafe` traits. The retained diagnostic is immutable; compile-time regression checks pin both traits.
- Accept ADR-0005 §19.1 and record ruling 13-V1-d1 grammar details; update the public API gate.
