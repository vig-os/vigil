# [PR 189](https://github.com/vig-os/vigil/pull/189) feat(audit): verifier input layer (#13 V3a-1)

## Description

Adds the crate-private input pipeline for #13 V3a-1. Native inputs use per-directory snapshot retries and numeric segment ordering, with live last. Shipped files and unordered batches retain physical locations and receive a sequence-sorted index. Inode aliases are read once, preferring segment names; distinct duplicate native names fail configuration.

A directory returns exactly the attempt whose listing `retry_snapshot` confirmed, per ruling 13-V3-d2. Discarded attempts leave no data or obligations. Native open/read errors remain tentative until the recheck: changed listings retry; stable unreadability returns the original I/O source. Explicit missing files fail immediately, and eight exhausted snapshots return I/O failure.

## Changes Made

- Stream physical lines through the existing classifier, compact decoded records immediately, and incrementally hash maximal spans. An oversized physical line remains one item through LF/EOF.
- Preserve source paths, physical lines, decoder items, checkpoint fields and pending native fragment/operator context for V3a-2/V3b.
- Use no locks, settlement, input mutation or network. Document per-directory consistency and live-review limitations privately.
- Keep the public API, chain engine, ADR statuses and changelog unchanged as required by the V3a-1 split.
