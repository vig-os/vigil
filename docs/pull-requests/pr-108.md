# [PR 108](https://github.com/vig-os/vigil/pull/108) feat(audit): KeyFileSigner and keygen (B3b)

## Description

Add the file-backed signer and durable key-file generator required by ADR-0005 decision 9: “`KeyFileSigner` is vigil's one implementation in 1.0” and “`vigil-audit keygen <file>` writes the seed (`0600`, never overwriting) and `<file>.pub` with the public key.” This PR supplies the library API; CLI wiring belongs to #13.

## Type of Change

- [x] `feat` -- New feature
- [x] `test` -- Adding or updating tests

### Modifiers

- [x] Breaking change (`!`) -- This change breaks backward compatibility

## Changes Made

1. Rename `KeySeed` to `KeyFileSigner`; remove the public hex parser, retain crate-visible `parse_hex_seed` and test-only `from_hex`, redact Debug, and update signer rustdoc and consumers. ADR-0005 d9: “The seed is held in `ed25519_dalek::SigningKey`, which zeroizes it on drop.”
2. Add `load(path: impl AsRef<Path>) -> Result<Self, SignerError>`, opening nonblocking/CLOEXEC and following symlinks. Check regular-file type, permissions, and effective ownership through `fstat` on the opened descriptor; read into a fixed zeroizing buffer with a 1024-byte cap. Activate `rustix/process` only with `audit` (d14). Apply **ruling B3b-d1**: the pure metadata helper takes `&Path` and returns complete path-bearing error messages. This correction needs no additional ADR amendment.
3. Implement the existing `Signer` methods with the verified signing key. ADR-0005 d9 specifies pure Ed25519, the public key, and zeroization on drop; no required trait methods change.
4. Add `keygen(path: impl AsRef<Path>) -> Result<[u8; 32], SignerError>`: exclusively create seed and appended `.pub` names before entropy/writes, use fixed zeroizing raw/hex buffers, write lowercase hex/LF, fsync seed/public/parent through the existing seam, and clean up only created files on failure. ADR-0005 d9: “never overwriting”; d6: “Directory fsync.”
5. Document seed/public-key ambiguity, trusted-key comparison, separate vigil/tessera keys, umask, partial-write rejection, and the cleanup path race. ADR-0005 d9: “Use the secret seed file, never the public key or `.pub` file” and “Use separate keys for vigil and tessera.”
6. Update the snapshot/allowlist under “ADR-0005 decision 13, ADR-0004 d1” and record amendment 7 in d9/d13; amendment 6 remains reserved for B3d1. The amendment covers signatures, file checks, effective uid versus OpenSSH's real uid, symlinks, size bound, create order, and cleanup.
