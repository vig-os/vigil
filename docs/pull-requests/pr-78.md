# [PR 78](https://github.com/vig-os/vigil/pull/78) docs(stability): state the 1.0 stability promise

## Description

Writes vigil's 1.0 stability promise. It documents decisions already taken in ADR-0001, 0002, 0004, 0005 and 0006 and invents no new ones. The one classification the ADRs did not yet state is that a semconv/`schemaUrl` change is a major. Issue #50 asks for it, and it is recorded in the ADR-0001 amendment.

## Type of Change

- [x] `docs` -- Documentation only

## Changes Made

- ADR-0001: dated "Amended" note and a new section "Versioning stance at 1.0". It covers what readers of the files are promised, what counts as a major, how upstream spec changes are absorbed, and the audit format's separate freeze (ADR-0005 decision 12).
- README: new "Stability" section covering the semver promise (`vigil_unstable` excluded), the on-disk format promise, the audit freeze, MSRV, platforms and what is not covered. macOS CI arrives with #46, and the section says so.
